# Hey Sonneblom V1.0 — Phase 1 design prototype

A responsive, static design prototype for the Hey Sonneblom thrift clothing shop and seller dashboard.

## Files
- `index.html` — public customer shop preview
- `admin.html` — seller dashboard visual preview
- `styles.css` — shared responsive styling
- `app.js` — small prototype interactions

## Run locally
Open `index.html` in a browser. Open `admin.html` to view the seller dashboard preview.

## Important
This is a front-end prototype only. It has no database, real product upload, authentication, checkout, payment processing, order storage, or push notifications yet. The sample product cards and dashboard numbers are demonstrations, not live stock.

## Next phase
Create the Supabase project and design the database, authentication, storage buckets, access policies and backend functions before connecting real customer or seller data.

## GitHub Pages
After creating a GitHub repository, upload these files to the repository root. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub will provide the published Pages address.
